## 💡 نصائح تغذية لتكيس المبايض

```
✅ ابعدي عن السكر المكرر والدقيق الأبيض
✅ الشوفان والشيا والبذور — أساس يومي
✅ القرفة تنظم الأنسولين — أضيفيها لكل شي
✅ 8 أكواب مي يومياً كحد أدنى
✅ البروتين في كل وجبة يقلل من الشهية
✅ الدهون الصحية (أفوكادو، زيت زيتون، مكسرات) مهمة للهرمونات
```
